## 🚀 Quick Start

### Option 1: Try in Browser (No Installation)
1. Click the **[Launch Binder](https://mybinder.org/v2/gh/mmahindaratne88/Artificial-Intelligence/HEAD)** badge above
2. Wait 2-5 minutes for the environment to build (first time only)
3. Navigate to any notebook in the JupyterLab file browser
4. Run cells interactively!

### Option 2: Run Locally
```bash
# Clone the repository
git clone https://github.com/mmahindaratne88/Artificial-Intelligence.git
cd Artificial-Intelligence

# Create virtual environment (recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Launch Jupyter Notebook
jupyter notebook
